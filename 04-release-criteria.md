# Release Entry / Exit Criteria

## Entry Criteria
- Requirement review passed
- Test environment ready
- Test case review completed

## Exit Criteria
- P0 case pass rate 100%
- P1 pass rate >= 95%
- Inventory diff ratio < 0.1%
- Stuck-order ratio < 0.5%
- No unresolved P0/P1 defects
- Performance targets met (P99 < 200ms)
